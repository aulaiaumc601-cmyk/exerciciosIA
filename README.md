# Exercícios de Python

Repositório criado para organizar exercícios e atividades desenvolvidos durante os estudos da matéria.

O conteúdo está separado em listas de exercícios, com códigos comentados e exemplos de saída para facilitar a leitura e o entendimento das soluções.

## Conteúdo

### Lista de 50 exercícios

Conjunto de exercícios voltados à prática dos conceitos de Python trabalhados em aula.

Os exercícios foram resolvidos individualmente e possuem comentários no código para explicar as principais operações realizadas.

### Exercícios de Data Science

Lista de exercícios envolvendo bibliotecas utilizadas para manipulação, análise e visualização de dados em Python.

Entre os conteúdos trabalhados estão:

- NumPy
- SciPy
- Pandas
- Matplotlib

Os exercícios incluem criação e manipulação de arrays, operações matemáticas, DataFrames, leitura de arquivos, tratamento de dados e criação de gráficos.

## Arquivos auxiliares

Alguns exercícios de Pandas utilizam arquivos externos para leitura de dados:

- `vendas.xlsx`
- `dados.csv`

Esses arquivos devem permanecer na mesma pasta do notebook ao executar os exercícios que utilizam `read_excel()` e `read_csv()`.

## Tecnologias utilizadas

- Python
- Jupyter Notebook
- NumPy
- SciPy
- Pandas
- Matplotlib

## Como executar

Os arquivos `.ipynb` podem ser executados utilizando:

- Google Colab
- Jupyter Notebook
- JupyterLab

No Google Colab, basta abrir o notebook e executar as células na ordem apresentada.

Para exercícios que utilizam arquivos externos, envie também os arquivos necessários para a sessão do Colab antes de executar a célula correspondente.

## Objetivo

O objetivo deste repositório é registrar a resolução das atividades propostas e praticar os conceitos apresentados durante as aulas, mantendo os códigos organizados e comentados para consulta e estudo.
